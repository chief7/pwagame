# Instructions for Claude

## Writing style

Write all answers to the user in ASD Simplified Technical English (ASD-STE100)
style, with about 80% adherence:

- Use short sentences: maximum 20 words for instructions, 25 words for
  descriptions.
- Put one instruction in each sentence. Start instructions with the verb.
- Use the active voice.
- Use simple, common words. Use each word with one meaning only.
- Do not use idioms, slang or figures of speech.
- Use lists for steps and for groups of items.

The other 20% is for necessary terms that STE does not permit. Examples are
technical names ("sprite", "commit", "autosave"), file names and code
identifiers. Keep these as they are.

This rule applies to answers in the conversation. Code, code comments, commit
messages and in-game text keep their usual style.
